
# Luopan Nusantara

A digital Feng Shui compass inspired by traditional Luopan wisdom.

## About

Luopan Nusantara is a digital exploration interface for traditional Feng Shui concepts, including:

- Direction Compass
- Manual Bearing Adjustment
- 24 Mountains
- Traditional Luopan concepts
- Responsive mobile interface

## Technology

- React
- TypeScript
- Vite
- CSS

## Development

Install dependencies:

```bash
npm install
```

Start development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

## Project Status

Initial interface development.

Compass sensor integration and AI interpretation are planned for future versions.
